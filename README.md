# 🚀 [Florece Studio / Portafolio]

Sitio web moderno, minimalista y de alto rendimiento, diseñado con una estética técnica y pulida (Glassmorphism), optimizado para ofrecer una experiencia de usuario fluida y un rendimiento impecable en cualquier dispositivo.

---

## 🛠️ Stack Tecnológico

* **Frontend:** HTML5, CSS3 (Variables personalizadas, Flexbox, Grid), JavaScript (ES6+ con loops de renderizado optimizados mediante `requestAnimationFrame`).
* **Estilos y Efectos:** Diseño tipo Glassmorphic, transiciones suaves y cursor personalizado con inercia física (lerp).
* **Despliegue y Hosting:** Vercel (con integración de despliegue continuo).
* **Analíticas:** Vercel Analytics & Google Analytics integrados.

---

## ✨ Características Principales

* **Cursor Personalizado Avanzado:** Punto central de precisión instantánea acompañado de un anillo exterior con inercia fluida y efectos de interacción al pasar sobre elementos interactivos.
* **Diseño Responsivo Total:** Adaptabilidad milimétrica en dispositivos móviles, tablets y escritorios, incluyendo menús y contenedores optimizados.
* **Formulario de Contacto Funcional:** Integrado con validaciones en tiempo real y listo para procesar mensajes de forma segura.
* **Optimización de Rendimiento:** Carga ultra rápida gracias a una arquitectura limpia sin dependencias pesadas de librerías externas de JavaScript.
